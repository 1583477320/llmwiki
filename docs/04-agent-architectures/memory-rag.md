# 记忆系统与多模态 RAG

> 长期记忆与检索增强生成 —— Agent 的知识管理中枢

## 为什么 Agent 需要记忆？

无状态的 LLM 每次调用都是「重新开始」。Agent 要在多轮交互和多个会话中保持连贯性，必须拥有记忆系统。

### 人类记忆的工程类比

| 生物记忆 | Agent 记忆 | 生命周期 | 技术实现 |
|---------|-----------|---------|---------|
| 工作记忆 | Context Window | 单次推理 | 对话历史 |
| 短期记忆 | 会话记忆 | 单次会话 | 滑动窗口/摘要 |
| 长期记忆 | 持久记忆 | 跨会话 | 向量数据库 + RAG |

## RAG 架构基础

RAG（Retrieval-Augmented Generation）是目前最主流的记忆检索范式。

### 标准 RAG 流程

```
写入：文档 → 分块(Chunking) → 嵌入(Embedding) → 向量数据库
查询：问题 → 嵌入 → 相似度检索 → Top-K 相关块 → 拼入 Prompt → LLM 回答
```

### 分块策略

| 策略 | 描述 | 适用场景 |
|------|------|---------|
| **固定大小** | 按 Token 数等分 | 通用场景 |
| **语义分块** | 按语义边界切分 | 技术文档 |
| **层次分块** | 父子块关系 | 长文档问答 |
| **Agentic 分块** | 由 Agent 决定切分策略 | 复杂知识图谱 |

### 嵌入模型

将文本映射到高维语义向量空间：

- **OpenAI**：`text-embedding-3-large/small`
- **BGE**：BAAI 开源，MTEB 中文评测领先
- **Jina AI**：支持 8K Context，多语言优化

### 检索策略演进

| 策略 | 描述 |
|------|------|
| **Naive Retrieval** | 单次检索 + 单次生成 |
| **Multi-hop Retrieval** | 多步检索，每次结果指导下一步查询 |
| **Self-RAG** | 模型自我判断是否需要检索，评估检索质量 |
| **Corrective RAG** | 检索后评估，不相关则重试或转向网络搜索 |
| **GraphRAG** | 结合知识图谱的结构化关系增强检索 |

## 多模态 RAG

传统 RAG 仅处理文本，Agent 需要处理多模态知识。

### ColPali / ColQwen 范式

新一代多模态检索方案，直接以视觉方式索引文档：

```
传统流程：PDF → OCR → 文本分块 → 文本嵌入 → 检索
ColPali： PDF → 页面截图 → 视觉嵌入 → 检索（保留排版、表格、图片信息）
```

**优势**：
- 无需 OCR 管道，避免误差传播
- 保留文档的视觉布局信息
- 表格、图表、公式等原生支持

### 多模态检索架构

```
用户查询（可含图片）
    │
    ├─→ 文本检索 → 文本嵌入 → Qdrant/Milvus
    │
    ├─→ 图像检索 → 视觉嵌入 → 向量数据库
    │
    └─→ 检索结果融合 → 重排序 → 拼入 LMM Context
```

### 多模态索引

| 模态 | 索引内容 | 嵌入模型 |
|------|---------|---------|
| 文本 | 文档段落 | text-embedding-3-large |
| 图片 | 截图/图表 | CLIP/ColPali |
| 表格 | 结构化数据 | 文本嵌入 + 元数据过滤 |
| 代码 | 代码块 | CodeBERT/UniXCoder |

## Agent 记忆系统的工程设计

### 三大模块

1. **语义记忆（Semantic Memory）**
   - 存储事实、概念、知识
   - 向量数据库 + RAG
   - 用户偏好、项目上下文等

2. **情景记忆（Episodic Memory）**
   - 存储历史交互序列
   - 时间戳索引 + 关键事件摘要
   - 用于反思和学习

3. **程序性记忆（Procedural Memory）**
   - 存储如何完成任务的流程
   - 存储在代码/配置中
   - 类似 System Prompt 中的规则和 SOP

### 记忆衰减与管理

```
┌────────────┐    重要性评分     ┌────────────┐
│  短期记忆   │ ───────────────→ │  长期记忆   │
│  (Redis)   │                  │ (Qdrant)   │
└────────────┘                  └────────────┘
      ↑                               │
      │        周期性整理/遗忘         │
      └───────────────────────────────┘
```

::: tip 核心权衡
记忆系统的本质是在**检索精度**、**检索速度**和**存储成本**之间的工程权衡。不是所有信息都值得被记住 —— 好的记忆系统需要主动的遗忘机制。
:::
